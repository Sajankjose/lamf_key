LAMF Encryption Key Generator

Upload a CSV with CID, Name, and Eligible Amount. This app will generate an encrypted key field that can be uploaded to MoEngage and passed in the landing page URL.

Important: This browser-only encryption is suitable for POC/UAT. For production, use backend token lookup because frontend decryption keys can be viewed by technical users.
Use the same secret in the landing page decrypt code.
Required headers: CID, Name, Eligible Amount
MoEngage URL format example:
https://yourdomain.com/lamf/?key={{UserAttribute['lamf_key']}}
